# SetlesStudio website audit — 1 November 2026

Scope: public sitemap crawl, website source review, and targeted SEO/security fixes. This is a first pass, not a claim that every possible issue has been found. Changes in this branch are not verified on production until deployment.

## Live checks

- Checked 25 URLs from the production sitemap: 24 returned HTTP 200; `/blog/test` returned HTTP 404.
- The bare domain correctly redirects to `https://www.setlesstudio.com/` with HTTP 308. An initial tool could not reach it; a direct check confirmed the redirect works.
- `robots.txt` and `sitemap.xml` both return HTTP 200. They are present, not missing.
- All 24 successful pages have canonical URLs and a page-level H1. The video-ads blog has an additional H1 inside its article body.
- No JSON-LD structured-data scripts were present on the crawled pages.
- Most static/service titles append `SetlesStudio` twice. Several blog metadata titles are truncated mid-word by the dashboard's automatic title generation.

## Remaining work and verification limits

- **Vercel team access:** Project listing works, but project-detail requests return HTTP 403 for the Setles Studio team. A team approval link was provided. Domain/deployment inspection and a verified production release require that grant.
- **Dashboard:** Implement real server-side authentication before restoring website blog writes. Move browser-only settings/content into the CMS if global editing is needed. Do not treat the local login as a security boundary.
- **Article HTML:** The existing markdown renderer accepts raw HTML from trusted CMS editors. Review HTML sanitization as part of restoring editing; this branch does not claim to sanitize all article HTML.
- **Content credibility:** Confirm and reconcile the homepage's 500+ projects and Learn page's 5,000+ projects. Substantiate claims such as 10x sales, 10x affordability, guaranteed realism, and client endorsements. This branch does not invent proof or alter the quoted testimonials.
- **Lead delivery:** The contact handler is wired to SMTP. No live inquiry or email was sent during this audit. Verify delivery with an explicitly authorized test and consider server-side abuse protection. The free-sample offer does not include a product-upload field; customers currently need a follow-up channel.
- **Search Console:** Actual index coverage, queries, rankings, manual actions, and field Core Web Vitals require Search Console data. A search returning no results is not proof that Google has indexed nothing.
- **Performance/accessibility:** Run mobile/desktop browser checks and measured Lighthouse/Core Web Vitals checks after deployment. Review image quality, navigation, contrast, keyboard behavior, animation, and contact-form interactions. No numeric score is claimed here.
- **Dependency maintenance:** This is a targeted framework patch, not a full framework-major migration or dependency/security certification.
